# 모바일 우선 UI

## 규칙

**주 사용 환경은 모바일이다. 모든 UI는 모바일 우선 반응형으로 설계한다.**

데스크톱에서 먼저 만들고 나중에 좁히는 순서를 쓰지 않는다. 좁은 화면을 기본 레이아웃으로 잡고 넓은 화면을 미디어 쿼리로 확장한다.

## 판단 기준

새 화면이나 컴포넌트를 만들 때 다음이 만족돼야 한다.

- 좁은 뷰포트에서 **가로 스크롤이 생기지 않는다**
- 탭 대상은 손가락으로 누를 수 있는 크기다
- 고정 픽셀 폭 대신 상대 단위·flex·grid를 쓴다
- 이미지는 `max-width: 100%`

## 넓은 화면 (2.0.0~)

- 헤더 한 벌 + 글자 탭(`Layout.tsx`)을 모든 화면 크기에서 같이 쓴다. 하단 탭바·사이드바를 따로 두지 않는다. 탭은 칸을 똑같이 나눠 가운데 로고와 맞춘다(넓은 화면은 가운데 560px). 하단 탭은 2.2.0 때 검토했으나 iOS Safari 주소창과 막대가 두 줄로 쌓여 보류
- 모든 탭은 헤더와 같은 폭을 쓴다(`.main` `max-width: 1200px`, `src/App.css`). 탭마다 따로 좁게 묶지 않는다(홈·모먼트의 760px 제한은 없앰)
- 포스트·사진 격자는 열 수를 고정하지 않고 `repeat(auto-fill, minmax(...))`로 폭에 맞춘다

## 따라오는 것
